Deter. Capture. Alert.

The locked Mac shows a warning, captures a fresh encrypted still and optional 12-second video-only clip, then sends it to the paired phone.

The alarm is loud by default. Quiet mode still records evidence and still alerts your iPhone.

Security claims you can verify.

The source, relay, build scripts, and threat boundaries are public.

01

Apple handles login

Arming completes only after macOS confirms its genuine lock state. There is no fake password screen.

02

Vision stays local

Scene and face-direction analysis use Apple frameworks on the Mac. There is no identity recognition.

03

Evidence is ciphertext

Camera evidence is encrypted before relay transport. The relay does see connection metadata and event type.

04

You control the noise

Sound requires an explicit setting. The default response is a visible warning and private evidence.

A deterrent.
Not a physical lock.

Someone can still close the lid, cut networking, power down, or damage the Mac. Keep Find My enabled and use a cable lock where appropriate.

Camera and recording laws vary. Use evidence capture only where lawful and provide any required notice.

Download. Move. Open.

The Mac app is free and open source. The current release is ad-hoc signed, so macOS asks you to approve the first launch.

  1. 1Download

    Get the latest crookcooked-mac.zip.

  2. 2Move

    Unzip it and move Crookcooked.app to Applications.

  3. 3Open once

    Control-click the app, choose Open, then confirm.
